### Phase 1: The Blueprint (Data Structure)

To make this work, we need to create specific "Buckets" (Database Tables) to hold your data.

#### 1. Core "Master" Data

* **Parties (Vendors/Customers):** Stores Name, GSTIN, Billing Address, Shipping Address.
* *Feature:* **Auto-Fetch:** We will use a script to hit a public GST API to fill these details when you type a GSTIN.
* *Feature:* **Excel Import:** We will use a library called `pandas` to read your Excel uploads and populate this table in bulk.


* **Products (Items):**
* *Fields:* Name (e.g., "White LDPE Granules"), Type (Raw Material, Finished Good, Asset, Consumable), HSN Code, GST Rate (%), Unit (Kg, Bags, Tons - Dropdown).
* *Logic:* Defines if the item is stockable or a service.



#### 2. Inventory & Production (The "Brain")

* **Batches:** Every time you buy scrap or produce granules, a unique `Batch ID` is generated.
* *Traceability:* If you sell "Batch #105," the system can look back and see it was made from "Scrap Batch #009" bought from "Vendor A."


* **Production Run:**
* *Input:* Select Raw Material + Weight (e.g., 500kg Scrap).
* *Output:* Select Finished Product + Weight (e.g., 450kg Granules).
* *Waste:* Auto-calculated or manually entered (e.g., 50kg Waste).
* *Logic:* When you click "Save," the system subtracts 500kg from *Raw Stock* and adds 450kg to *Finished Stock* instantly.



#### 3. Sales & Logistics

* **Invoices:**
* *Fields:* Customer, Date, Payment Terms, Vehicle No., Transport Mode (Road/Rail).
* *Line Items:* Product, Quantity, Rate, Discount, GST Amount (Auto-calculated).


* **Vehicles:**
* *Fields:* Registration No., Type (Own/Third-party), Driver Name.
* *Logic:* If "Own," we can add a module later to track fuel/maintenance costs.



#### 4. Compliance (GST & E-Invoice)

Yes, absolutely. That is the exact definition of the **Django** approach we are taking.

**How it works:**
You are essentially building your own private website.

* **On Android:** You will open the Chrome browser and type in your system's address (e.g., `192.168.1.5:8000`). It will load just like a webpage.
* **On Windows:** You open your browser and do the same.
* **No App Stores:** You never need to build an `.apk` file or install an `.exe` on other machines. If you update the code on your main PC, everyone else sees the update instantly when they refresh their page.

This architecture ensures that all your data (invoices, products, vendors) lives in **one central database** (on your main PC or a cloud server later), and every device just "views" it through the browser.
